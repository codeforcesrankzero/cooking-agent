# Cooking Agent

Telegram-бот на базе LLM, который подбирает рецепты по продуктам, которые уже есть дома, и рассчитывает стоимость докупки недостающих ингредиентов.

## Что делает

- **По продуктам:** «У меня курица и рис» → подбирает рецепты из имеющихся ингредиентов
- **По сценарию:** «Ужин на свидание», «Быстрый обед для спортивной недели» → семантический поиск подходящих рецептов
- **Комбинированно:** «Есть лосось, хочу что-то праздничное» → ингредиентный + семантический поиск
- **Стоимость докупки:** показывает, что нужно докупить и сколько это стоит (цены парсятся с Перекрёстка)
- **Многоходовый диалог:** уточнения, фильтрация, альтернативы

## Стек

- Python 3.11+, FastAPI, aiogram
- SQLite (рецепты, цены) + ChromaDB (векторный индекс для семантического поиска)
- Embedding: `intfloat/multilingual-e5-small`
- LLM: OpenAI API (GPT-4o-mini)

## Данные

| Данные | Источник | Объём |
|---|---|---|
| Рецепты | [Food.com Recipes and Reviews](https://www.kaggle.com/datasets/irkaal/foodcom-recipes-and-reviews) | ~80K рецептов (название, ингредиенты, шаги, время, теги) |
| Рецепты (резерв) | [RecipeNLG](https://www.kaggle.com/datasets/paultimothymooney/recipenlg) | 2M+ рецептов |
| Цены на продукты | [Каталог Перекрёстка](https://www.perekrestok.ru/cat), парсинг раз в 3 дня | ~100 базовых продуктов |
